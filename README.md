## 先说清楚：IX 专线和普通 IPLC 差在哪

IX 指的是互联网交换中心（Internet Exchange Point）。普通 IPLC 专线给你一个公网入口 IP，你从家宽、办公室直接连上去就行；而 IX 专线的入口只存在于交换中心的内网里，没有公网路由，只跟阿里云、腾讯云、华为云这类云厂商的 BGP 网络交换路由。

这带来两个直接后果：

- **你没法从普通家宽直接连 IX 专线**，必须先有一台支持范围内的云厂服务器（俗称“前置机”），通过云厂内网接入专线。
- **入口不暴露公网 IP**，几乎不存在被公网扫描和大规模 DDoS 直接打到的面，也明显降低了被扫描通报的概率。代价是通报风险没有消失，而是转移到用户侧——云厂商实名体系下，出了违规流量，追责路径非常清晰。

第三方测评（虎窝博客、catcat.blog 的实测）给出的整体判断比较一致：IX 的链路本身问题不大，真正的门槛在于前置机的选择和配置，以及前置带宽是否真的给得足。阿里云、腾讯云轻量实例标称 200M 峰值，但已有不少被限速到 20M 甚至 1M 的案例；火山云延迟表现好，但按量流量费（约 0.8 元/GB）长期跑并不便宜。前置机的钱，要算进总成本里。

## 购买前必须知道的几件事

这几条都来自官方服务条款和知识库，属于买了才发现会很被动的类型：

- **全部产品需要实名认证**，且仅限正规用途。商家对“正规用途”的定义是不进行回国等违法行为。
- **退款政策偏严**：开通后 24 小时内、且存在质量问题（需要提交具体的延迟、速度数据佐证）才支持退款，不支持开通后更换地域。没有“不满意随便退”这回事。
- **没有 SLA 保证**。商家自述上一年突发故障约 3 次（不含提前公告的维护），需要 SLA 保障得走定制询价。
- **出口不支持入站**。出口 IP 不能用来公开建站、支付回调、邮件接收或对外游戏服务端，业务必须是 VPS 主动向外访问的模式。
- **升降级走工单**，降级到更低价套餐时差价不退，是否迁移、能否保留 IP 以工单处理结果为准。

## 常见问题

**沪日 IX 和沪日 IPLC 延迟差多少？** 官方对两条线给的端内参考都是 25~28ms，第三方实测也没有拉开明显差距。IX 因为多了一段前置网络，理论上会引入少量额外延迟，但主要体现在前置机选得好不好，而不是线路本身。

**家庭宽带能不能连沪日 IX？** 不能。IX 入口只在 IXP 内网宣告，只有支持范围内的云厂 BGP 网络可以连入。想要家宽直连，选上海电信入口的沪日 IPLC。

**IP 能保证是“干净”的原生 IP 吗？** 不保证。官方明确出口均为服务器 IP，不保证原生、住宅或流媒体解锁。第三方测评显示其 IPv4 在 scamalytics 上风险评分表现不错，但这属于实测参考，不是合同承诺。

**支持 IPv6 吗？** 官方资料目前不足以确认所有套餐的 IPv6 支持，业务必需的话下单前先提交工单确认，别默认双栈。

**超量之后会怎样？** 流量计费套餐按上下行双向统计，达到额度后暂停服务，可以自助购买流量重置，或提交工单补差价升级套餐。
